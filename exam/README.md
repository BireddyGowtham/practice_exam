# B.Pharm MCQ Practice Website

A standalone browser-based MCQ practice test created from the supplied Excel file.

Features:
- 508 MCQs loaded from the Excel file
- 60-minute countdown timer
- Automatic submission when time reaches zero
- Previous / Next navigation
- Question navigator palette
- Answered/unanswered tracking
- Final score percentage
- Correct, wrong, and unanswered counts
- Answer review after submission
- Restart test
- No backend or internet connection required

## Run
Open `index.html` in Chrome, Edge, or Firefox.

The Excel data is embedded directly into `index.html`, so the website works offline.
